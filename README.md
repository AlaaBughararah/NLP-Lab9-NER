# NLP Lab 9: Named Entity Recognition

This lab explores Named Entity Recognition (NER) using spaCy to identify and classify entities such as people, organizations, locations, and products.

## Lab Activities

- Extract named entities and display their details.
- Prepare entity annotations and check token alignment.
- Visualize entities using displaCy.

## Tasks

1. Identify named entities in a user-provided sentence and print their details.
2. Add missing entities to a paragraph, count PERSON and ORG entities, and visualize the results.
3. Train a custom NER model for 20 iterations, save it, reload it, and display its predictions.

## Tools

- Python
- Jupyter Notebook
- spaCy
- displaCy

## Note

The custom model uses one training example for demonstration. Its output on the training text does not measure performance on new sentences.
